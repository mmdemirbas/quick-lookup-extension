Chat

The panel can discuss the page you are reading with Claude. This is the only feature that sends page content anywhere: right-clicking a page and choosing Discuss this page with Claude sends that page's readable text to Anthropic's API. Nothing is sent without that gesture, and nothing at all is sent while no key is stored.

Start it with ./ctl dev bridge from this repository. It prints the address to paste above, and ./ctl pair puts its token on the clipboard. Answers then come from Claude Code with tools switched off, so nothing it is told by a web page can run anything on this machine.

A larger budget sends more of the page and costs more. The panel says when a page was longer than the budget, so an answer about half a page is never presented as an answer about the page.

Dictionary packs

A pack is a dictionary file kept on this device. It answers instantly, works offline, and has no daily allowance. FreeDict publishes one for most language pairs — English to Turkish is 36,589 head-words with pronunciation.

  1. Download a dictionary in dictd or StarDict form, for example from freedict.org.
  2. Unpack the archive. Browsers cannot read .tar.xz, so this step has to happen outside the extension.
  3. Choose every file it contained: .index and .dict.dz, or .ifo, .idx and .dict.dz. A tab-separated .tsv of word and definition works too.
